---
title: Optional full condition
---

By requiring a full condition and providing a default for the {@linkcode UseThen} and {@linkcode UseElse} capabilities, you can create a condition that defaults to specific types when the capabilities are not explicitly defined. This allows for a more flexible yet strict evaluation of conditions, ensuring that all cases are accounted for while still providing sensible defaults.
